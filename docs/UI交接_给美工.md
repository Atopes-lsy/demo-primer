# 界面视觉交接 · 给美工

---

## 一、你要做的是什么

这是一个**千牛客服工作台的右侧插件面板**。你负责它的外观 —— 配色、字号、圆角、过渡速度。

**代码你不用碰，你只需要改一个文件：**

```
frontend/src/index.css
```

---

## 二、先把它跑起来

### 方式 A：在这台电脑上直接改（最省事）

项目现在只在这台电脑上。你如果和开发者在同一台机器前，直接：

```bash
cd frontend
pnpm dev
```

浏览器打开提示的地址（通常是 `http://localhost:5173`）。

**然后改 `src/index.css`，保存，页面立刻就变** —— 不用刷新、不用重新编译、不用重启。

### 方式 B：在你自己的电脑上改

**第一步，装两个东西：**

1. **Node.js**（版本 20 或更高）→ https://nodejs.org 下载安装
2. **pnpm** → 装完 Node 后，打开命令行（Windows 搜索"cmd"）输入：
   ```
   npm i -g pnpm
   ```

**第二步，把这两个文件夹放到同一个目录下：**

```
随便起个名字/
├── frontend/     ← 主项目
└── data/         ← 口径表
```

> ⚠️ **`data/` 必须和 `frontend/` 平级，不能少。**
> 前端要读 `data/koujing.json`（客服话术的口径表），这是**唯一**一个
> 跨出 `frontend/` 的文件。少它，页面直接白屏报错。
> 这不是你的问题，是缺文件 —— 跟开发者要一下就行。
>
> **开跑前先对一眼**，这两个必须都在：
> ```
> frontend/package.json
> data/koujing.json
> ```

**第三步，在那个目录下：**

```bash
cd frontend
pnpm install     # 只需要第一次跑，装依赖，大概一两分钟
pnpm dev
```

## 三、你只改这一个文件

打开 `frontend/src/index.css`，它长这样：

```css
@import 'tailwindcss';

@theme {
  /* ★ 你改这里 —— 全是「令牌」，也就是设计变量 */
  --color-brand: #2b7fff;
  --text-body: 11px;
  ...
}

@layer base {
  /* 别动 */
}

@utility scrollbar-thin {
  /* 别动 */
}
```

**为什么改这一个文件就能全站生效？**
组件里的颜色和字号全都写成 `bg-brand`、`text-body` 这样的**引用**，指向 `@theme`
里的令牌。改令牌的值，所有引用它的地方一起变。

## 五、三条规矩

### 规矩 1 · 只改值，不改名字

```css
--color-brand: #2b7fff;    /* 原来 */
--color-brand: #1a6eff;    /* ✅ 改值，可以 */
--color-brand2: #1a6eff;   /* ❌ 加新名字，组件不认，改了没效果 */
```

**为什么**：令牌名是**组件和样式之间的接口**。组件里写的是 `bg-brand`，
它去找 `--color-brand`。你把它改名成 `--color-primary`，全站蓝色当场消失。

### 规矩 2 · 要加新令牌，先问开发者

如果你需要一个新颜色（比如"提示黄"），跟开发者说，由他加。
你自己加的不会被任何组件引用，等于白加。

### 规矩 3 · 别动 `src/components/` 下面的文件

那些是 `.tsx` 组件文件，是开发者正在改的地方。两边同时改会互相覆盖。

**你的工作面就是 `index.css` 一个文件。**

## 八、几个你大概率会问的问题

**Q：改字号为什么只有 4 档？**
A：原先有 60 处字号是**硬编码**在 14 个组件文件里的（主要是 10px 和 11px），
刚收进这 4 档。所以现在改一处，全站一起变。

**Q：10px 和 11px 只差 1px，能合并成一档吗？**
A：能，但**先说一声** —— 合并会同时影响 60 处。这是历史遗留，不是刻意设计。

**Q：改字号时，行高会跟着变吗？**
A：**分两半，你要知道区别：**

| 令牌 | 行高行为 |
|---|---|
| `--text-xs` `--text-base` | 行高是**倍数**（1.33 倍），你改字号它**自动跟着缩放** |
| `--text-note` `--text-body` | **只有字号，行高靠继承**。改字号，行高不动 |

所以 `text-note` / `text-body` 这两档你改大改小时，最好连行高一起定。
跟开发者说一声，在令牌下面加一行就行：

```css
--text-body: 11px;
--text-body--line-height: 18px;   /* ← 加这行，就变成固定行高了 */
```

**Q：文件里的 `--text-xs` 注释写"框架内建"，是什么意思？**
A：我们用的样式框架 Tailwind 自带了一套字号，`text-xs` 是它自带的名字。
组件里有 24 处在用。我在文件里把它显式写出来了，这样四档能排在一起看。
**你可以照常改它的值**，没有区别。

**Q：怎么知道某个颜色影响哪一块？**
A：**改一下值，保存，页面立刻变。** 比翻文档快得多 —— 这也是为什么建议你跑起来改。

**Q：改坏了怎么办？**
A：`index.css` 只有一个文件，改坏了把原文件覆盖回来就恢复。放心改。
