## 二 · `涉个体差异` 换模型 —— 但**先要接口线修装配**，否则换了也读不到

**现状。** `pipeline.py:392`

```python
def 涉个体差异(主张: str, 顾客情况: Sequence[tuple[str, str]] = ()) -> bool
```

v9 对这件事的要求很明确（文档串原样抄了）：

> **顾客小卡每条消息都读**，所以 LLM 读小卡时**本来就知道顾客是孕妇**。
> 判断「涉不涉及个体差异」时**读小卡，不从主张里抠关键词** → 顾客分两句说也不会漏。

而代码现在**两条都读，小卡优先**，文档串自己承认小卡那一支读不到东西：

> **但主张那一遍暂时还不能删 —— 拦路的不是「装配层还没建」。** 装配层
> （`app/data/装配.py`）早就建好、也接在请求路径上了，但 `装配._这是谁` 填进
> 「值」的是**买家昵称**，身体情况不在那儿（演示里那两格是「小鹿」「阿沅」）。
> 而本函数只读「**值**」，不读备注 —— **所以小卡这一支今天结构上就点不响，
> 主张那一遍是唯一真正生效的输入。**

**所以这一项分两半，顺序不能反：**

| 半 | 谁 | 内容 |
|---|---|---|
| ① 装配把身体情况写进「这是谁」的**值** | **接口线**（本单 §二 的前置，我已写进它的工单 §九 9.2） | 「怀孕／敏感肌／病史」从哪来、谁抽 |
| ② 把关键词换成一次分类调用 | **你** | 输入就读 `顾客情况`，不再是主张 |

**顺序反了会做出一个永远读不到输入的实现** —— 换完还是只有主张那一遍生效，
肉眼看不出区别，测试也照样绿。

**验收。** 拿**「消息里不出现「孕妇」二字、只在背景里说」**的句子验，例如
`S00474` 那条的后半句（「我怀孕三个月了，之前一直在用」）—— 按 v9 的拆法
「怀孕三个月」**不拆成主张**，只留在小卡里。**换模型之后这一条必须判 `True`**，
关键词版在它上面必然漏（文档串举的就是这个反面例子）。

⚠️ 换完这一处，「规则层可重放」的说法**又要收窄一格**（文档串里那句
「换掉之后这一层就不再可重放」就是为这天写的）。文档那半是**文档线**的活，
但你 docstring 里别写反。
