## 验证与尺寸

- `pnpm run build`（tsc -b + Vite）和 `pnpm run build:ui-review`。
- `oxlint src scripts`。不要把 node_modules 纳入 lint；本地快照根目录 lint 会扫描依赖，产生无关告警。
- `scripts/check-send-policy.ts`：五顾客六源、13项发送边界。
- `scripts/check-review-actions.ts`：模拟报备/转交、重复点击幂等、转交发送锁定、原始样本不变。
- 1280×720 默认三槽150/252/198px、输入框190px，五场景同高；操作回执不挤高卡片。
- 1440×900、减少动态效果、快速切换顾客需回归。长真实内容/主动展开详情允许局部滚动，不能隐藏数据换取“无滚动”。
