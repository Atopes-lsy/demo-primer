# Primer 使用说明

这是一个客服辅助工具。**你不需要安装任何东西**，Python、依赖、界面、数据全在这个文件夹里。

---

## 一、怎么打开（就三步）

**第 1 步：先解压。**

右键点 `PRIMER.zip` → 选「全部解压…」→ 位置选**桌面**。

> ⚠️ 一定要先解压。直接在压缩包的窗口里双击里面的文件，是跑不起来的
> —— 那种情况下只会解压出你要双击的那一个文件，旁边的文件夹全都不在。

**第 2 步：进 `PRIMER` 文件夹，双击 `启动.bat`。**

**第 3 步：等 5～10 秒。** 会出现一个黑色窗口，浏览器会**自己打开**。

要是浏览器没自己打开，就自己打开一个，地址栏敲：

```
http://localhost:8000/
```

---

## 二、什么样算正常

- **黑色窗口**最后几行会写：`Uvicorn running on http://127.0.0.1:8000`
- **浏览器**里是一个三栏界面：左边一列会话、中间是聊天记录、右边是判定结果。

只要这两样都在，就是跑起来了。

---

## 三、怎么关掉

**把那个黑色窗口关掉就行。** 关掉之后浏览器就打不开了，这是正常的。

下次要用，还是双击 `启动.bat`。

---

## 四、出问题了，对号入座

| 你看到的 | 是怎么回事 | 怎么办 |
| --- | --- | --- |
| 黑窗口一闪就没了 | 多半是在压缩包里直接双击的 | 先「全部解压」，再从解压出来的文件夹里双击 |
| 浏览器说「无法访问此网站」 | 还没起来，或者起崩了 | 等 5 秒按一下 F5；还不行就看黑窗口最后几行字 |
| 黑窗口说「8000 端口已经有东西在跑了」 | 你已经开过一个了 | 看浏览器里那个界面，用那个就行；不行就把黑窗口全关掉重来 |
| 黑窗口说「找不到 Python 运行时」 | 解压不完整 —— 杀毒软件有时会把 `python.exe` 直接删掉 | 关掉杀毒软件的实时防护，把压缩包重新解压一次 |
| 解压出来的文件名是乱码 | 用了第三方解压软件 | 改用 Windows 自带的：右键 →「全部解压…」 |
| 右栏顶上那行写「剧本兜底 · 判定」，不是「接口 · 已连」 | 真模型那一问没答上来（断网／额度用完／密钥失效） | 界面照样能走完演示，只是判定结果用的是兜底剧本。要真结果就查网络和额度 |
| 左边一列只有两条示例会话 | 会话列表那个接口没答上来 | 把黑窗口关掉，重新双击一次 `启动.bat` |

**上面都没写，或者黑窗口里是一串报错**：把**黑窗口里的内容**截图发给技术同学，
别只发「打不开」—— 那几行报错就是原因。

## 五、两件应该知道的事

1. **它要联网。** 判定是把顾客对话发到阿里云百炼的模型上算出来的。
   演示用的数据没问题，但**别拿真实顾客的隐私数据来试**。

2. **包里带着一把模型密钥。** 能用多少取决于账户余额。
   如果判定突然全都不出结果，很可能是额度用完了 —— 找技术同学。

---

## 六、给技术同学的一段（不懂可以跳过）

- 界面不是一个单独的网页服务：后端 `:8000` 同源托管了 `frontend/dist`，
  所以只有一个窗口、一个地址。前端的请求本来就是相对路径（`fetch('/api/…')`），
  同源之后 `vite.config.ts` 里那段代理在生产路径上用不上。
- 解释器是随身带的（`runtime/python/`），依赖通过 `PYTHONPATH` 指向
  `backend/.venv/Lib/site-packages`。**发出去的包里没有 `pyvenv.cfg`** ——
  venv 靠它那行 `home = <本机绝对路径>` 找解释器，换台机器必然起不来。
- 程序会往 `data/先例库.json` 回写，所以**别解压到只读的位置**
  （`C:\Program Files` 之类），桌面、文档、D 盘都行。
- 重新打包：`backend/.venv/Scripts/python.exe 交付/打包.py`
  （需要先 `cd frontend && npm run build`，`dist/` 不在 git 里）。
